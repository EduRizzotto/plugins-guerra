# Plugins Guerra (PaperMC 26.3 / API 1.21+)

Repositório com o código-fonte e os .jar compilados dos plugins customizados do servidor.

## 📦 Plugins incluídos

### 1. \TeamsPlugin\
- Sistema de Clãs/Times (\/team criar\, \/team convidar\, \/team placar\, chat de clã, etc.)
- Placar em molduras no lobby (\/placar\ / \/team placar\)

### 2. \ConstructionWandPlugin\
- Varinhas de Construção (Ferro, Diamante e Netherita) baseadas no mod Construction Wand
- Menu de opções (\/wand\ ou Shift + Clique Direito no ar)
- Reparo na Bigorna e upgrade de Diamante para Netherita na Mesa de Ferraria

## 📁 Estrutura
- \TeamsPlugin/src/\ — Código-fonte do TeamsPlugin
- \ConstructionWandPlugin/src/\ — Código-fonte do ConstructionWandPlugin
- \compiled-jars/\ — Arquivos \.jar\ já compilados prontos para colocar na pasta \plugins/\ do servidor Paper
